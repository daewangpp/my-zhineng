🎯 诊断报告 IndexError 第 4 行

列表长度为 3,有效索引是 0-2。range(len(scores)+1) 产生 0-3,当 i=3 时访问 scores[3] 超出范围。

📖 列表索引越界📖 差一错误
RAG 引用知识库:KB001 列表索引越界、KB012 差一错误(off-by-one)
🔧 修复方案
将 range(len(scores) + 1) 改为 range(len(scores)),避免索引越界
scores = [85, 92, 78] total = 0 for i in range(len(scores)): total += scores[i] print(total)
运行结果:
255
💡 三段式讲解
考点定位
列表索引越界与循环边界控制。Python 列表索引从 0 开始,长度为 n 的列表有效索引范围是 0 到 n-1。
错因分析
初学者常混淆"元素个数"与"最大索引",误以为 range 需要覆盖到长度本身,导致多生成一个无效索引。
原理解读
range(n) 生成 0 到 n-1。去掉 +1 后,循环恰好遍历所有合法索引,避免访问不存在的第 4 个位置。
